## 🎯 O QUE FAZER AGORA?

### Passo 1: Conseguir os arquivos

**Pergunte para quem te passou o projeto:**
> "Oi! Como eu baixo os arquivos do dashboard do Automaton? Você tem o link do GitHub ou pode me enviar os arquivos?"

### Passo 2: Colocar em D:\agentes

Quando você tiver os arquivos:
1. Crie a pasta `D:\agentes` (se não existir)
2. Coloque todos os arquivos lá dentro

### Passo 3: Instalar Node.js

1. Vá em: **https://nodejs.org/**
2. Baixe a versão LTS (botão da esquerda)
3. Instale (Next, Next, Next, Install)

### Passo 4: Rodar

1. Duplo clique em: **instalar.bat**
2. Escolha opção 1 (Dashboard)
3. Espere instalar
4. Duplo clique em: **rodar-dashboard.bat**
5. Abra o navegador: **http://localhost:3000**
